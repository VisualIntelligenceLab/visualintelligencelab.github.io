论文与知识产权

论文清单按年度归档，录用后两周内上线；专利与软件著作权在申请提交后再公开，避免影响新颖性。

类型状态公开方式
期刊 / 会议论文录用后 2 周本页 + arXiv / 出版方链接 + 代码仓库
预印本投稿即挂arXiv，附复现说明
专利申请提交后仅公布名称与申请号，不公开实施细节
软件著作权登记完成后名称、登记号、对应仓库
03

怎么用我们的代码

Step 1

克隆与环境

按 README 用 conda 建环境，先跑 smoke test，确认 CUDA 可用再训练。

Step 2

复现基线

用给定配置复现论文指标，差距超过 5% 先别改模型，查数据与预处理。

Step 3

提 issue

带上环境、命令、日志三段信息。我们承诺 3 个工作日内首次响应。

代码默认 MIT；文档 CC BY 4.0；模型权重单独许可，商用请联系 visualintelligence@163.com。
